Starry Night


What it does and my motivation

Starry Night is a real-time night light that helps me light up my room at night and set designated sleeping times. It responds to a remote control by changing colors depending on which button is pressed, and based on the inner clock it turns on/off and plays a sound that also doubles as an alarm.


Bill of Materials

  • Remote control & remote control sensor (for changing color and sensing button presses)
  • Real-time clock (for keeping track of time)
  • RGB LEDs (for the night light)
  • Passive buzzer (for alarm sounds)
  • Assorted resistors (for current-limiting)
  • Arduino board, bread board, jumper wires (to program and build circuit)
  • USB power supply (for powering the project)
  • Cardboard or 3D printing (for housing circuit)

Timeline and Contingencies

  • Draw a schematic, calculate any needed resistor values, pseudocode
  • Test buzzer, LEDs, remote control, and RTC to understand how it works
  • Build and program circuit and test
  • Test and create some container/housing for circuit
  • If the remote control doesn’t work, I’ll use a button to switch states
  • If the real-time clock doesn’t work, I’ll use a photoresistor
